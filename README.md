# Vara's Modpack - IRON NEST

Official installer releases for **Vara's Modpack - IRON NEST**, a fire control room mod for
*Iron Nest: Heavy Turret Simulator*.

- Mod page (Nexus): https://www.nexusmods.com/ironnest/mods/55
- This repository hosts release binaries only - no mod source code is published here.

Download the latest installer from the **Releases** page (right side of this repo, or
https://github.com/Vararepo/IronNestMods/releases/latest - this link never changes between versions).
